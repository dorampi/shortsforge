Privacy Policy

Last updated: 7 September 2026

ShortsForge is a desktop application that runs on its user's own computer. There is no ShortsForge server, no hosted account, and no analytics. This policy explains what the Software stores and where.

What is stored, and where

Everything the Software stores is kept in files and a local database on the user's own machine. Specifically:

  • Access and refresh tokens for accounts the user connects, so uploads can continue without logging in again.
  • The connected account's display name and identifier, shown in the interface so the user can see which account a video will go to.
  • Video projects — titles, descriptions, tags, source links, timecodes, and the rendered video files.

What is not collected

The Software does not collect analytics, does not profile users, does not read other people's TikTok or YouTube data, and does not transmit any of the data above to the author or to any third party.

Where data is sent

Network requests go only to services the user has chosen to use: the platform the user is uploading to, the video sources the user points the Software at, and the music library the user searches. A video is uploaded only when the user asks for that specific video to be uploaded.

Deleting data

Disconnecting an account from within the Software erases its stored tokens. Access can also be revoked at any time from the platform's own account settings. Deleting the Software's working directory removes all remaining local data.

Children

The Software is not directed at children and is not intended for use by anyone under the minimum age required by the platforms it connects to.
